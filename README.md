# Diabetes Tracker

A Ukrainian-language nutrition and health tracking web app, built for a Type 2 diabetic with Stage 3 gastritis and no gallbladder. Helps plan small frequent meals, track carbs/GI/GL/fat per meal, and log blood sugar readings.

## Status

Early planning stage — the requirements interview with the end user (mom) hasn't happened yet. See [docs/build-log.md](docs/build-log.md) for the current state and next steps.
